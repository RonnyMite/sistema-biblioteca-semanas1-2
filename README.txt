# Sistema de Biblioteca - Semana 2

Proyecto en Python que implementa:
- Encapsulación con atributos privados y getters/setters.
- Herencia: LibroFisico y LibroDigital heredan de Libro.
- Herencia: Estudiante y Docente heredan de Usuario.
- Composición: Biblioteca contiene libros, usuarios y préstamos.
- Asociación: Prestamo relaciona un Libro con un Usuario.
- Enum EstadoLibro.

## Ejecución

Abre una terminal dentro de esta carpeta y ejecuta:

python main.py

No requiere librerías externas.
